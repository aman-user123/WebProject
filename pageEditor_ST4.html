Validation

I used the W3C Markup Validation Service to check each of my pages (profile, sitemap, content). All passed without errors. Minor acceptable warnings noted for accessibility. See my Validation Page for full results and screenshots.

My Role

As Student 4, I was responsible for implementing the following:

  • User Profile
  • Sitemap
  • Content Page
  • Validation

Techniques Used

Profile Page

Used Flexbox for layout, percentage skill bars with inline styles, and styled forms with custom inputs and hover states. Accessibility is ensured using label elements, alt text, and appropriate color contrast.

Sitemap Page

Built with SVG elements and interactive links using <rect>, <text>, and includes hover color change and keyboard accessibility via CSS and tabindex.

Content Page

Organized into internal sections with anchor links and “Go to Top” functionality. Used images and structured text with headings for clarity.

Challenges

Making SVG nodes responsive and accessible was a key challenge. I resolved it by adjusting viewBox settings and using semantic `` with meaningful alt texts.

Accessibility

All pages use alt text, semantic HTML, color contrast, and keyboard navigation support to meet WCAG 2.1 standards.

Compliance

Pages follow HTML5 and WCAG 2.1 accessibility standards, using proper structure, responsive design, and semantic markup.
