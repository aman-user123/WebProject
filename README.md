Climate Action – SDG 13 Awareness Website
A multi-page responsive website built to raise awareness about Sustainable Development Goal 13: Climate Action. Developed as an academic project at the Informatics Institute of Technology, affiliated with the University of Westminster, UK.

 About the Project
This website promotes climate action awareness through a clean, accessible, and well-structured web experience. It covers key information about SDG 13 and provides a consistent, user-friendly interface across all pages.
 Pages

Content Page — Main informational page covering SDG 13 climate action topics
User Profile Page — Dedicated profile page for site users
Page Editor — Interface for managing and editing page content
Validation Page — Form validation and input handling
Sitemap — Full site navigation overview for improved accessibility

 Technologies Used

HTML5
CSS3
Responsive Design principles
Semantic HTML structure

 Features

Fully responsive layout across different screen sizes
Consistent design patterns and styling across all pages
Dedicated sitemap page for easy navigation
Clean, maintainable and well-structured codebase
Separate CSS files per page for modular styling
